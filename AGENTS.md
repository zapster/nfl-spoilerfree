# Repository Instructions

## Spoiler-Free Output

- Do not include NFL game scores or outcomes in assistant responses, progress
  updates, or summaries unless the user explicitly asks for them.
- When discussing game-related behavior, describe changes without revealing
  scores or outcomes.

## Commit Messages

- When a change addresses a GitHub issue, include `Fixes #<issue-number>` in
  the commit message so GitHub closes the issue when the commit reaches the
  default branch.
